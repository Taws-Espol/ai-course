In this assignment, you will personalize the course website and practice the local development workflow. The goal is to make a small, reviewable change that demonstrates you can edit Markdown, run the site locally, and explain what changed.

## Objective

Update one course page with clear Markdown content and verify that the page renders correctly on the local Jekyll site.

Your update should include:

- At least two section headings.
- One internal link to another course page.
- One code block or table.
- A short explanation of what you changed and why.

## Requirements

Choose one page from the site and improve it. You may edit a lecture, tutorial, resource page, or staff profile.

Your page should be easy to scan. Use headings for structure, lists for grouped details, and code blocks only when showing commands or source code.

Example Markdown structure:

```markdown
## Goal

Explain what this page helps students do.

## Steps

1. Run the local server.
2. Edit the Markdown file.
3. Refresh the browser.
```

## Deliverables

Submit:

- A link to your pull request or commit.
- A screenshot of the rendered page.
- A short note describing one issue you checked before submitting.

## Grading

| Category | Points |
| --- | ---: |
| Clear Markdown structure | 30 |
| Correct local rendering | 30 |
| Useful explanation | 25 |
| Clean Git history | 15 |

## Notes

Do not edit generated files in `_site`. Those files are build output. Make changes in the source Markdown, layout, or Sass files instead.
